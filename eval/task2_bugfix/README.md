## 建议注入的 4~5 个 bug

1. 标准化用错轴：`(x - x.mean()) / x.std()` 对二维数组按全局算，应该 `axis=0`
2. 维度处理：`reshape` 顺序写反，或忘了 `[:, None]` 导致广播方向错
3. 数值计算：整数除法 `//` 应为 `/`，或 `int()` 截断而非 `round()`
4. 异常输入：空列表 / 全 NaN 列时抛 `ZeroDivisionError` 或 `RuntimeWarning`
5. off-by-one：窗口求和 / 移动平均的边界少算或多算一个
